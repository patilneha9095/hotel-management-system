# 🏨 Hotel Management System

A full-stack hotel management and room booking system designed to simplify hotel operations and provide a smooth booking experience for customers.

## 🎯 Project Objective

The main objective of this project is to develop a centralized hotel management platform where customers can search and book rooms, while hotel staff and administrators can manage rooms, reservations, guests, payments, and hotel operations.

## 👥 User Roles

### Customer
- Register and login
- Search available rooms
- View room details
- Book rooms
- Manage bookings
- View booking history
- Give ratings and reviews

### Receptionist
- Manage guest check-in and check-out
- View reservations
- Manage guest information
- Track room status

### Admin
- Manage rooms
- Manage bookings
- Manage customers
- Manage staff
- Manage payments
- View reports and analytics
- Manage hotel settings
